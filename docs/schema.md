# Felkyo Creatures — Database Schema

This document describes the database in plain language: every table, what it is
for, and why it is shaped the way it is. Keep it updated whenever the schema
changes (the schema itself changes only through Phinx migrations — never by hand).

---

## Status

The full schema was **designed and approved in increment 0.2** and is created by
the migrations in `migrations/`. This document is filled in as those migrations
are built. (In increment 0.1 there are no tables yet — only the empty databases
`felkyo` and `felkyo_test`.)
